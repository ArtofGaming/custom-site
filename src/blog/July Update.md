# Tea!
Early this month I got my first matcha set and first portion of matcha powder! It was pretty fun to make and I really like the taste of my matcha lattes. I got things pretty much down on the second try although I think I need to mix the powder for a little bit longer. When I saw that it was recommended to put syrup in there, I thought I had found some weird AI thing but no. Syrup is the perfect sweetner for this. I also got some favorites from my usual tea shop which were great as usual. I'm careful about my caffiene intake so I don't often enjoy my oolong and matcha in the same day but some days its fine.

# Game dev
Last month I participated in the Only One of Any Asset Jam for the second time. I think if this had been any other jam making a game in a week that month would've burnt me out. But luckily that jam is all about doing a lot with a little. I like how my entry turned out, especially since I chose to be very experimental. The sprites were literally silohuettes and 1/3 of the game didn't have visuals to highlight that the only place we got to truly see into was the bathroom. If you're into terrible relationships and uncommon presentation give it a try. (A link is on my games page!) I also wrote a post mortem about it. It felt good to actually try and promote a game, even if not very much.

This month I finally finished the update for You're My Angel, the game my team made for Otome Jam 2026. Due to my move, I hadn't gotten time to do anything fun with the scripting and there were some visual bugs as well. Now I'm proud to say those problems should all be fixed and there's even a web build now!(Link is also on my games page!)
